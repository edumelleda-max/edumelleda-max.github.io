> SD Association 자료를 정리했습니다. 직접 시험하지 않았습니다. 현재 제휴링크가 없습니다.

**A2 카드만으로 앱이 빨라지는 것은 아닙니다.** 기기가 앱 저장과 A2 성능을 지원하는지 먼저 확인하세요.

## A1·A2는 앱 성능 등급입니다

A1·A2는 앱 사용에 필요한 랜덤 접근 성능과 순차 전송 성능의 기준입니다. A2 성능을 활용하려면 카드뿐 아니라 연결 기기도 A2를 지원해야 합니다.

## 구매 전 네 가지를 확인하세요

1. 기기가 microSD 카드를 지원하는가?
2. 앱이나 앱 데이터를 카드에 저장할 수 있는가?
3. 기기 제조사가 A2 지원을 명시하는가?
4. 카드에 어떤 앱 성능 등급이 표시돼 있는가?

microSD를 꽂을 수 있어도 앱 저장이나 A2 기능까지 지원하는 것은 아닙니다. 설명서에 없다면 기기 모델명과 사용 목적을 알려 제조사에 문의하세요.

## 영상 촬영용 기준과는 다릅니다

영상 촬영이 목적이라면 [SD카드 속도 등급](/posts/sd-video-class/)을 확인하세요. 앱 성능 등급만으로 고르면 안 됩니다.

이미 필요한 기능을 지원하는 카드가 있다면 등급만 높이려고 교체할 필요는 없습니다.
