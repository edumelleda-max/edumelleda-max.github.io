G304 X SUPERLIGHT는 AA 배터리를 넣는 기존 모델과 달리 충전해서 써요. 연결은 LIGHTSPEED 무선 어댑터, 블루투스, USB-C 케이블을 지원해요. 배터리를 교체하는 대신 충전해서 쓸 마우스를 찾는다면 살펴볼 제품이에요.

제조사 공식 자료를 바탕으로 정리했으며, 직접 사용한 후기가 아니에요.

## 배터리를 바꿀 건가요, 충전할 건가요?

X SUPERLIGHT가 붙지 않은 기존 모델은 AA 배터리 한 개를 사용해요. X SUPERLIGHT는 충전식이에요. 두 제품을 구분할 때는 이름 끝의 X SUPERLIGHT와 전원 방식을 함께 보면 돼요.

배터리 교체 방식을 유지하고 싶다면 충전식이라는 이유로 신형을 고를 필요는 없어요. 충전해서 쓰는 쪽을 원한다면 아래 X 모델이 후보예요.

## 연결 방식은 이렇게 나뉘어요

~~~text
G304 X SUPERLIGHT
  ├ LIGHTSPEED 무선 어댑터 → 어댑터로 무선 연결
  ├ 블루투스              → 블루투스로 연결
  └ USB-C 케이블          → 케이블로 연결
~~~

| 원하는 사용 방식 | 고를 연결 |
|---|---|
| PC에 어댑터를 꽂고 무선으로 사용 | LIGHTSPEED |
| 블루투스로 연결하는 기기에서 사용 | 블루투스 |
| 무선 대신 선을 연결해서 사용 | USB-C 케이블 |

충전식 전원만 볼 게 아니라, 필요한 연결 방식이 있는지도 함께 판단하세요. 지금 마우스가 손에 잘 맞고 연결에도 불편이 없다면 새 모델이라는 이유로 바꿀 필요는 없어요.
