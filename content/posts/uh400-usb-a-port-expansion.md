이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

노트북의 USB-A 포트가 부족하다면 UH400을 후보로 볼 수 있어요. USB 포트를 네 개로 늘려 키보드나 마우스를 번갈아 빼는 일을 줄여요. USB-C 포트만 있는 노트북에는 직접 꽂을 수 없어요.

TP-Link 공식 자료를 정리했으며, 직접 사용한 후기가 아니에요.

## 노트북에 꽂는 쪽부터 봐요

UH400의 입력은 USB-A예요. 본체에 붙은 케이블을 노트북에 꽂고, 사용할 USB 장치를 허브에 연결해요. 연결 케이블을 따로 준비할 필요는 없어요.

~~~text
노트북 USB-A → UH400 → 키보드
                    ├→ 마우스
                    └→ USB 메모리
~~~

USB-C 포트만 있다면 USB-C 입력 허브를 고르는 편이 간단해요. 상품 설명에서 노트북에 꽂는 입력 단자와 주변기기를 꽂는 출력 단자를 나눠 보세요.

## 모니터나 유선랜도 연결할 건가요?

| 필요한 연결 | 선택 기준 |
|---|---|
| USB-A 주변기기를 꽂을 자리 | UH400 같은 USB 허브 |
| USB-C 노트북에 주변기기 연결 | USB-C 입력 허브 |
| 모니터 또는 유선랜 연결 | 필요한 영상·랜 단자가 있는 제품 |

UH400의 출력 구성은 USB 포트예요. 모니터나 유선랜까지 연결하려고 산다면 필요한 단자가 따로 있는지 먼저 구분해야 해요.

## 포트 수와 전송 속도는 달라요

USB 규격은 3.0이지만, 포트를 늘린다고 연결 장치의 전송 속도까지 빨라지는 것은 아니에요. 제조사도 실제 속도가 연결한 장치 설정에 제한된다고 안내해요.

쓰는 장치를 노트북에 모두 직접 꽂을 수 있다면 허브를 추가할 필요는 없어요. USB-A 장치가 많아 자주 바꿔 꽂는 경우에 아래 상품을 살펴보세요.
