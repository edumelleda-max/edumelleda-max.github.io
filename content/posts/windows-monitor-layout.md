> 마이크로소프트 공식 안내를 정리했습니다. 직접 시험하지 않았습니다. 현재 제휴링크가 없습니다.

왼쪽 모니터로 가려는데 마우스를 오른쪽으로 움직여야 한다면 **Windows의 화면 배치부터 바꾸세요.**

## 설정의 화면 위치를 실제 모니터와 맞추세요

1. 설정 → 시스템 → 디스플레이를 엽니다.
2. ‘식별’로 각 모니터의 번호를 확인합니다.
3. 설정 화면의 모니터를 실제 위치대로 끌어 놓습니다.
4. 적용한 뒤 마우스가 원하는 방향으로 넘어가는지 확인합니다.

실제 왼쪽 모니터가 2번이면 설정에서도 2번을 왼쪽에 놓으세요. 번호를 바꿀 필요는 없습니다.

## 같은 화면은 ‘복제’, 넓게 쓰려면 ‘확장’

Win+P를 누르면 표시 방식을 고를 수 있습니다.

- **복제:** 여러 모니터에 같은 내용을 표시합니다.
- **확장:** 여러 모니터에 창을 나눠 놓고 작업할 수 있습니다.

## 모니터가 설정에 나타나지 않으면

설정 → 시스템 → 디스플레이 → 여러 디스플레이에서 ‘검색(Detect)’을 시도하세요. 메뉴 이름은 Windows 버전에 따라 다를 수 있습니다.

두 모니터가 이미 인식된다면 케이블을 바꾸기 전에 배치부터 확인하세요. 케이블의 영상 지원이 궁금하다면 [USB-C 가이드](/posts/usb-c-cable-guide/)를 참고하세요.
