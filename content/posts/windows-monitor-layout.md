> 공식 문서 기반 정보 글이며 직접 사용하거나 시험한 결과가 아닙니다. 현재 제휴링크가 없습니다. 확인일: 2026-10-22 UTC.

왼쪽 모니터로 마우스를 옮기려는데 오른쪽으로 나가야 한다면, 먼저 Windows의 화면 배치를 확인해 보세요. 이미 연결된 모니터의 설정을 정리하는 글입니다.

## 화면 번호와 책상 위치 맞추기
설정 → 시스템 → 디스플레이에서 식별 기능으로 각 화면의 번호를 확인합니다. 설정에 보이는 화면을 실제 책상 위치에 맞춰 끌어 배치하고 적용하세요. 이어서 마우스를 화면 사이로 움직여 예상한 방향으로 넘어가는지 확인합니다.

예를 들어 실제 왼쪽이 2번, 오른쪽이 1번이면 그 위치를 먼저 메모하세요. 번호 자체를 바꾸려 하기보다 위치를 맞추는 데 초점을 둔 편집 예시입니다.

## 같은 화면인가, 넓은 작업 공간인가
Win+P의 복제는 같은 내용을 여러 화면에 표시합니다. 확장은 데스크톱을 여러 화면으로 넓혀 창을 옮길 수 있게 합니다. 발표 자료를 함께 보여줄지, 문서 두 개를 나란히 놓을지에 따라 목적을 선택하세요.

| 확인할 것 | 내 선택 |
| --- | --- |
| 왼쪽·오른쪽의 식별 번호 | 왼쪽 __ / 오른쪽 __ |
| 표시 목적 | 복제 / 확장 |
| 적용 후 마우스 이동 | 예상대로 / 추가 확인 |

## 설정에 화면이 없다면
설정 → 시스템 → 디스플레이의 여러 디스플레이에서 검색(Detect)을 시도할 수 있습니다. 메뉴 번역은 버전에 따라 다를 수 있습니다. 이 조작이 모든 연결 문제를 해결한다는 뜻은 아닙니다.

설정에 두 화면이 잡힌 상태에서 위치만 다르다면 장비 교체보다 배치 점검이 먼저입니다. 화면 연결용 케이블을 따로 검토할 때는 [USB-C 용도 구분](/posts/usb-c-cable-guide/)에서 충전과 영상 조건을 구분하세요.
