### 소리가 안 날 때 확인 흐름

```text
[케이블 볼륨·음소거 표시등]
             ↓
[컴퓨터 USB에 직접 연결]
             ↓
[앱·운영체제 입력/출력 선택]
             ↓
[앱 다시 열고 음성 확인]
```

공식 점검 항목을 정리한 흐름도예요. 고장 원인을 확정하는 순서는 아니에요.

버튼을 눌렀다는 기억보다 표시등을 확인하는 습관이 실수를 줄이는 데 도움이 돼요. 회의 전에는 앱의 마이크 입력 표시나 테스트 기능으로 내 목소리가 들어가는지도 확인하세요. 헤드셋 버튼과 앱의 음소거 아이콘이 항상 함께 바뀐다고 가정하지 마세요.

## 내 회의 방식과 맞나요?

| 쓰는 상황 | 구매 전 판단 |
| --- | --- |
| 책상에서 회의하고 음소거를 자주 한다 | 케이블 버튼을 손 닿는 곳에 둘 수 있는지 보세요. |
| 회의하면서 방을 오간다 | 유선 연결이 이동에 맞는지 먼저 따져보세요. |
| 이미 헤드셋이 있고 앱 단축키가 편하다 | 지금 장비로 불편한 점이 없다면 그대로 써도 돼요. |

마이크 붐은 회전시켜 쓰지 않을 때 옆으로 치울 수 있어요. 붐을 올리는 동작을 음소거 버튼 대신 쓰지는 마세요. 제조사 자료에서 그 동작의 자동 음소거 기능을 확인한 것은 아니에요.

## 소리가 안 나거나 상대가 못 들으면

공식 안내서의 점검 순서는 다음과 같아요.

- 케이블의 볼륨을 확인하고 음소거 표시등이 깜박이는지 봐요.
- USB가 제대로 연결됐는지 확인해요. 허브를 쓰고 있다면 컴퓨터 USB 포트에 직접 연결해 점검해요.
- 회의 앱과 운영체제에서 출력 장치와 마이크 입력 장치를 각각 확인해요.
- 설정을 확인한 뒤 앱을 다시 열어 시험해요.

소리는 다른 스피커로 나오고 마이크만 헤드셋으로 잡힐 수 있으니, 입력과 출력을 따로 보는 게 핵심이에요. 운영체제별 메뉴 이름은 달라질 수 있어요.

## 착용감은 버튼만 보고 판단할 수 없어요

구매 전에는 컴퓨터의 USB 단자와 판매 옵션, 앉은 자리에서 케이블이 닿는지 확인하세요. 장시간 착용감과 마이크 음질은 이 글에서 시험하지 않았어요. 버튼이 편리해 보여도 착용감까지 좋다고 단정할 수는 없어요.
