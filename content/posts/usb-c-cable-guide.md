애플 240W USB-C 충전 케이블도 데이터 전송은 USB 2 규격이에요. 외장 SSD에 쓸 거라면 충전 전력보다 데이터 규격부터 봐요. [애플 제품 사양](https://www.apple.com/shop/product/myqt3am/a/240w-usb-c-charge-cable-2-m)

상품을 볼 때는 **2m·블랙·1개** 옵션과 모델명을 확인해요. 가격·재고·배송·보증 조건은 판매 페이지에서 확인해요.

## 1. 충전용이라면 기기와 충전기부터 봐요

기기와 충전기의 지원 전력을 먼저 확인해요. 케이블의 최대 사양만 보고 충전 속도를 판단하지는 않아요.

애플은 해당 케이블을 호환 USB-C 전원 어댑터와 함께 쓰도록 안내해요. 어댑터는 별매예요. 길이와 구성품도 비교하려면 [두 충전 케이블 비교](/posts/usb-c-charging-comparison/)를 참고해요.

## 2. 파일을 옮긴다면 데이터 규격을 봐요

‘고속충전’ 표시만으로 파일 전송 성능을 판단하기는 어려워요. 케이블과 컴퓨터, 저장장치의 데이터 규격을 확인해요.

삼성 T7이 느려서 새 케이블을 찾는 중이라면 [연결 점검부터 해봐요](/posts/ssd-cable-checklist/).

## 3. 모니터에 연결한다면 영상 지원을 봐요

케이블의 영상 지원, 기기의 출력 규격, 모니터의 입력 규격을 확인해요. 아이폰은 [모델별 연결 조건](/posts/iphone-display-check/)을 먼저 보면 돼요. 다른 기기에 같은 조건을 그대로 적용하지는 않아요. [애플의 USB-C 연결 안내](https://support.apple.com/en-us/105099)

## 구매 전에는 이것만 확인해요

- 충전, 파일 전송, 화면 연결 중 필요한 용도
- 기기와 케이블의 규격
- 필요한 길이와 구성품

제품 설명에 필요한 사양이 빠져 있으면 모델명으로 제조사에 물어봐요. 인증 표기가 궁금하면 [USB 인증 목록 확인 방법](/posts/usb-certification-check/)도 참고할 수 있어요.
