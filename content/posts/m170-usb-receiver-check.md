이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

M170의 커서가 움직이지 않으면 전원과 배터리 방향을 보고, USB 수신기를 컴퓨터에 직접 꽂아 보세요. 로지텍 설명서가 먼저 안내하는 점검이에요. 연결이 돌아오면 새 마우스를 살 필요는 없어요.

제조사 자료를 정리한 글이며, 직접 사용한 후기가 아니에요.

## 수신기가 어디에 꽂혀 있나요?

M170은 USB 수신기를 컴퓨터에 꽂아서 써요. 수신기가 책상에 보이지 않으면 마우스 내부 보관 공간을 먼저 살펴보세요.

허브에 꽂혀 있다면 컴퓨터의 USB 포트로 옮겨요. 이미 직접 꽂혀 있다면 다른 USB 포트에서 반응을 확인하세요. 전원 스위치가 켜져 있는지, 배터리가 표시된 방향으로 들어가 있는지도 함께 봐요.

```text
[전원 켜짐 · 배터리 방향]
            ↓
[USB 수신기 연결 확인]
            ↓
[허브 제외 → 컴퓨터에 직접 연결]
            ↓
[다른 USB 포트에서 반응 확인]
```

## 포인터만 불안정하면 표면도 바꿔 봐요

설명서는 다른 표면에서 움직여 보고, 마우스와 수신기 사이의 금속 물체를 치우도록 안내해요. USB 포트와 표면을 한꺼번에 바꾸기보다는 하나씩 바꿔야 어느 조작 뒤에 반응이 달라졌는지 알기 쉬워요.

| 바꿔 본 것 | 확인할 결과 |
|---|---|
| 전원·배터리 방향 | 커서가 움직이기 시작하는가 |
| 허브 대신 컴퓨터 직결·다른 포트 | USB 연결 위치를 바꾸면 반응이 달라지는가 |
| 표면·사이의 금속 물체 | 포인터 움직임이 달라지는가 |

반응이 돌아온 연결과 표면을 그대로 사용하면 돼요. 계속 반응이 없다면 위 결과를 적어 제품 지원에 전달하세요. 단순한 연결 점검 결과만으로 수신기나 마우스 중 어느 쪽이 고장인지 정해 새 부품을 사지는 마세요.
